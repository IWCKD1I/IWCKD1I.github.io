Qualitest

A RAG assistant that reads a failed automated test and tells engineers why it broke and how to fix it.

  • Three-phase dataset: human labelling → RAG enhancement → AI augmentation over Playwright & Puppeteer failure reports.

02Construction · AECAgent

Mensura

Chat with DWG/DXF construction drawings — counts, lengths, areas, quantity takeoffs and BoQ reconciliation.

  • The LLM never does arithmetic: it calls 20+ deterministic geometry tools built on ezdxf, Shapely and Postgres.
  • Every number is cited back to entity handles you can click to highlight on the drawing.
  • 8-layer architecture: ingest → normalise → geometry → tools → agent → BoQ → reconcile → UI, traced with Langfuse.
